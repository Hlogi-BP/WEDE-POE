### 1\. Project Overview

In this project, I am building a professional website for **Pfuna Vahn Help Mense**, a Pretoria-based NPO founded in 2017. The goal is to initiate their online presence and establish a cohesive brand identity that encourages community support and donations for their homeless shelter.



### 2\. Website Goals \& Objectives

**Establish Online Visibility:** Move from a single-page AI-generated presence to a professional multi-page site.

**Increase Awareness:** Provide detailed information about community services.

**Engagement KPIs:** Target 500+ monthly visitors and 10–20 donation enquiries within the first 3 months.



### 3\. Sitemap

The website consists of five core pages designed for clear navigation and user flow:

**Home (index.html):** Hero section, mission summary, and primary Call to Action (CTA).

**About (about.html:** Organisational history, leadership, mission, and vision.

**Services (services.html):** Details on shelter, nutrition, and counseling programs.

**Enquiry (enquiry.html):** Interactive form for volunteering and sponsorship/donations.

**Contact (contact.html):** Contact details, multi-location info, and embedded map.



### 4\. Design \& Technical Stack

The site follows the "Warmth and Simplicity" branding strategy:

**Colour Palette:** Soft Blue (trust), Warm Orange (community), and Off-White (professional).

**Typography:** Poppins (Headings) and Open Sans (Body).

**Layout:** Built using **modern CSS Flexbox** for navigation and content alignment.

**Responsiveness:** Uses **Media Queries** and **Relative Units (rem/em)** to ensure the site scales across desktop, tablet, and mobile devices.

### 6. Changelog (Part 1 to Part 2 Improvements)

The following changes were made to the project following Part 1 feedback and Part 2 technical requirements:

**Semantic Structure:** Converted basic links into a full HTML5 structure using `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>` tags for better accessibility.

**Layout Engine:** Replaced static alignment with **CSS Flexbox** to manage the navigation menu and main content areas.

**Responsive Units:** Migrated from absolute `px` units to relative **`rem`** and **`em`** units to support browser scaling.

**Mobile Optimisation:** Added a **768px breakpoint** with media queries to stack navigation vertically on mobile devices.

**Visual Polish:** Implemented advanced CSS including `box-shadow` on the navigation bar, `border-radius` on images, and `:focus/:active` pseudo-classes for interactive elements.

**Content Update:** Added a second location to the Contact page and implemented an iframe Google Map as requested in the brief.
